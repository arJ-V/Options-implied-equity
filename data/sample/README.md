# Sample signals panel

`signals.parquet` is a **committed demo dataset** so the Streamlit dashboard works on [Streamlit Cloud](https://share.streamlit.io) without downloading ~1.3 GB of raw options data.

| Field | Value |
|-------|-------|
| Symbols | SPY, QQQ, IWM |
| Dates | 2024 only |
| Rows | ~755 |
| Source | Output of `python run_signals.py` on the starter release |

For the full 2020–2024 panel, run the pipeline locally — see the root [README](../../README.md).
